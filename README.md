Minecraft 自动化部署与启动平台 MinecraftLauncher0.01.1041.2发行说明
发布日期：2026年11月12日
作者：轩奶 xuannai（XUANNAITTOTS）
适用平台：Windows 10 / 11 (x64)

感谢使用 Minecraft 自动化部署与启动平台！这是一个专为 Windows 打造的轻量级、开箱即用的 Minecraft 启动器与管理工具。
它集成了版本下载、模组获取、Java 环境自动配置与游戏启动功能，专为追求纯净体验与高效的玩家设计。

核心特性
 1. 极速实例部署
官方正版同步：支持一键获取 Mojang 官方所有正式版与快照版本。

多线程并发下载：内置强力下载引擎（带进度条与速度显示），采用官方与 BMCLAPI 镜像双通道回退机制，大幅提升文件下载速度。

深度完整性校验：下载自动进行 SHA1 校验，剔除损坏文件，确保游戏核心文件绝对纯净。

 2. 模组中心 (Modrinth 接入)
海量模组检索：内置 Modrinth 官方 API，支持按游戏版本与主流加载器（Forge / Fabric / NeoForge / Quilt）精准筛选。

依赖智能补全：下载模组时，自动解析并下载所需的依赖模组（前置库），告别“缺前置”烦恼。

国内镜像加速：对接国内 Modrinth 镜像，解决页面加载缓慢与下载失败问题。

 3. 智能 Java 环境管理
版本自动匹配：根据游戏版本自动判断所需 Java 版本（Java 8 / 17 / 21 等）。

纯净源加速下载：自动从国内高评分镜像（清华 TUNA、中科大、南大）拉取轻量级 JRE 包，失效自动切回官方源。

开箱即用：下载完成后自动解压并绑定至游戏实例，无需手动配置系统环境变量。

 4. 稳定与性能优化引擎
彻底防锁死：启动前自动清理残留进程、释放系统级文件锁与单例锁，彻底解决频繁重启导致的崩溃问题。

防闪退机制：优化 JVM 参数传递逻辑，完美兼容 Java 8 的 @argfile 限制；修复 lwjgl 等核心库路径过滤错误，避免“找不到主类”或“缺少 GLFW”报错。

无黑框启动：优先使用 javaw.exe 唤起游戏，保持桌面干净清爽。

内存深度清理（可选）：内置 C# 内存回收引擎，在启动前释放系统冗余工作集，为游戏腾出更多可用内存。

 修复与改进 (对比历史版本)
修复了在外部文件夹调用脚本时，相对路径错乱导致无法找到 mods 或 Java 的问题（全面启用 $PSScriptRoot 锚点）。

修复了特定网络环境下 Java 下载失败的问题，全面改用 Invoke-WebRequest 原生同步下载。

修复了部分版本依赖库过滤逻辑，确保所有核心原生库均被正确加载。

优化了控制台日志输出，崩溃时自动提取 latest.log 尾部信息以便于排查。

 目录结构说明
请确保启动器与以下文件夹保持同级目录，请勿随意修改文件夹名称：

text
📁 启动器根目录
 ├── 📄 MC.exe (或 启动器启动.bat)
 ├── 📁 Java/         (自动下载的 Java 运行环境)
 ├── 📁 mods/         (模组存放目录)
 ├── 📁 versions/     (游戏实例与运行库)
 └── 📄 username.txt  (记录你使用的离线玩家名称)
 重要注意事项
杀毒软件误报：如果您使用的是打包后的 .exe 版本，由于 PowerShell 打包机制，Windows Defender 或 360 可能会误报。请将程序所在目录加入白名单/信任区。

离线模式：目前启动器采用离线模式（离线 UUID 生成），不支持正版微软账号登录。

内存分配：默认分配 -Xmx2G 内存，若您的电脑内存较大且游玩大型整合包，可自行修改生成的 java.args 文件。
